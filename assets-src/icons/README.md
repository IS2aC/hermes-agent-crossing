ICÔNES D'ÉTAT 16x16 ANIMÉS
Icônes affichées au-dessus des agents pour indiquer leur état:
- Normal: Aucune icône ou symbole neutre (optionnel)
- Dégradé/bloqué: Nuage orange #f79b39 avec éclairs périodiques
- Approbation requise: Moustache de vérification #ffca4e qui apparaît/disparaît
- OK: Coche verte #74b100 qui apparaît avec un léger bounce
- Réflexion: Nuage réfléchissant #a39cff avec idée (ampoule?) qui apparaît
- Touché/Down: PANSEMENT BLANC sur membre + ÉTOILES DORÉES #ffca4e qui tournent autour
  * Lecture immédiate: doit être clairement identifiable comme "blessé" même en petite taille

Animation:
- Boucle fluide, 4-6 frames par seconde
- Format: Aseprite avec frames d'animation, export PNG séquentiel ou sprite sheet
- Alternative: GIF animé pour prévisualisation, mais utiliser PNG+sprite sheet en jeu

Dimensions: 16x16 pixels (grille de base)
Style: Cohérent avec l'esthétique pixel art frais et calme
