# Avant l'étape 07

L'étape 07 ne peut pas commencer sans ces informations, que seul l'opérateur peut fournir.

1. **Accès à Hermes (Q2).** Comment y accéder, quelle version ? Un profil de test à outils limités existe-t-il, ou peut-on en créer un ? Un message envoyé à un agent peut déclencher de vraies actions sur le serveur.
2. **JARVIS et VEILLEUR (Q3).** Que sont-ils dans Hermes : profils, personas, autre chose ?
3. **Activité externe (Q7).** Faut-il voir ce que les agents font depuis Telegram, le CLI ou le cron ? La documentation publique ne montre pas de flux global. C'est le plus gros risque produit (R1).

- **Licence du projet :** le dépôt n'a pas encore de fichier `LICENSE`.
